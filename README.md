# 📚 Estudo Ativo com NotebookLM — Finanças Pessoais e Investimentos

> Projeto de aprendizagem ativa usando IA **grounded** (fundamentada exclusivamente
> nas fontes selecionadas). O NotebookLM é limitado a um repositório curado de
> materiais, reduzindo alucinações e garantindo um ambiente de estudo confiável.

---

## 🎯 Objetivos de Aprendizagem

Ao final deste estudo, o aluno deve ser capaz de:

1. **Compreender** a diferença entre renda fixa e renda variável.
2. **Entender** a dinâmica da taxa Selic e o impacto da inflação no poder de compra.
3. **Aprender** a estruturar uma reserva de emergência antes de investir.
4. **Dominar** o vocabulário básico do mercado financeiro.
5. **Aplicar** prompts estruturados para extrair conhecimento das fontes.

## 🗺️ Roteiro Passo a Passo

### Etapa 1 — Criar o caderno no NotebookLM
- Acesse https://notebooklm.google.com
- Crie um caderno: **"Estudo Ativo: Finanças Pessoais e Investimentos"**
- Faça upload das 3 a 5 fontes curadas (ver `fontes/curadoria.md`).

### Etapa 2 — Definir objetivos de aprendizagem
- Já descritos acima. Use-os como bússola para os prompts.

### Etapa 3 — Executar perguntas estratégicas
- Use os prompts do arquivo `prompts/prompt-book.md`.
- Compare variações (simples vs. estruturado) usando `prompts/matriz-testes.md`.

### Etapa 4 — Sintetizar no miniguia
- Consolide as notas em `miniguia/miniguia-final.md`.
